"# Place-wise" 

A web-based platform designed to help students prepare for placements, 
improve their skills, discover opportunities, and track their preparation.

## 🚀 Features

- Student Registration & Login
- Student Profile

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind.css
- Router

### Backend
- NOde.js
- Tailwind CSS

### Database
- MongoDB

### Others Tools
- Git & Github
- JWT Authentication
